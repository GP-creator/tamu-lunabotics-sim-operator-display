# Handoff for Alice: LichtBlick layout with GNC-2027 topics

From Gadadhar, 2026-11-04. The layout is your deliverable; this note explains what was added so it can work with the GNC team's topics as well as our `/sim/*` simulation.

## What exists

- **Source:** `TAMU-Lunabotics/GNC-2027` (public), commit `52c04c2` (2026-11-03), read from source; **not run**. Their interface doc (`docs/INTERFACES.md`) marks these interfaces WORKING, not final.
- **Second layout:** `lichtblick_layout_gnc2027.json`, generated by `tools/make_gnc_layout.py` from our sim layout. It uses the same look, safety settings and CONNECTION panel, with only topics GNC-2027 actually publishes. Topic list with producers: `gnc2027_topics.txt`. Panel table: `panel_topics_gnc2027.md`. Figure: `pdr/figures/layout_diagram_gnc2027.png`.
- **Check:** `python3 tools/validate_layout.py 02_Ground_Station_Telemetry/deliverables/lichtblick/lichtblick_layout_gnc2027.json --no-sim --known 02_Ground_Station_Telemetry/deliverables/lichtblick/gnc2027_topics.txt` → PASS (15 panels, 3 scripts, 13 topics; every topic has a GNC-2027 producer). The User Scripts compile under strict TypeScript.
- **Why a second file:** LichtBlick 1.30.0 layouts have no topic-alias mechanism, and the GNC topics have different message types (e.g. `TwistStamped`, custom status messages), so a separate layout file is the honest option.

## Cautions

1. **Custom messages over Rosbridge:** `GuidanceStatus` and `PlannerStatus` are `luna_interfaces` types. Rosbridge can only serialize them if `luna_interfaces` is built and sourced where Rosbridge runs. Replay from MCAP is fine (schemas are embedded).
2. **Latched topics:** `/map`, `/guidance/path`, `/planning/status` and `/guidance/status` are transient-local and publish on change. A panel opened late shows the last value only if Rosbridge picks up the latched QoS; check this when testing live.
3. **Do not publish `/goal_pose`:** the GNC planner takes goals on `/goal_pose`. Our layouts redirect LichtBlick's click-to-publish to `/operator_display/click_disabled/*`, so the display cannot send a goal. Keep it that way.
4. **Not tested live:** the GNC stack was not built or run here; layout correctness is from source and the validator only. Next step: build GNC-2027 (`level1.launch.py` + `guidance.launch.py`), add Rosbridge, open this layout, and record an MCAP for `tools/verify_mcap.py` (it finds Odometry/Path topics by type).
5. **Missing for a judge-visible display** (GNC's own doc lists map and planned path as CURRENT REQUIREMENTS): a LiDAR/scan topic, a camera image topic, and a source label (sim vs rover). These need CDH/GNC topic decisions (Sabu + Robin, GNC).
